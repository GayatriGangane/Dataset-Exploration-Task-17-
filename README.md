# Dataset Exploration Using Pandas

## Project Overview

This project focuses on exploring and understanding the basic structure and characteristics of a dataset using Python and Pandas.

The Iris Dataset is used for the analysis. Various Pandas functions are applied to understand the dimensions, columns, data types, statistical properties, missing values, and categorical information in the dataset.

## Objective

The main objective of this project is to explore a dataset before applying machine learning or data analysis techniques.

The project demonstrates how to:

- Load a dataset
- Display the first and last records
- Check dataset dimensions
- Identify column names
- Understand data types
- Generate statistical summaries
- Identify numerical and categorical columns
- Check missing values
- Analyze categorical distributions
- Draw basic observations from the dataset

## Dataset

The Iris Dataset contains information about three species of iris flowers:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The dataset contains 150 observations and 5 columns.

### Features

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width
5. Species
